## 1. Целевая аудитория: допущения

МТЛ позиционируется **шире крипто-ниши** — как социальное движение свободных людей, проект гражданской самоорганизации, децентрализованное сообщество.

Соответственно, рекламные каналы и CPM/CPC оцениваются для **широкой целевой аудитории** (civic tech, activism, alternative finance, governance, personal freedom), а не только для крипто-специфичной.

## 3. Воронка: оценка конверсии

Типичная воронка для проекта с широким позиционированием (civic/governance):

```
Impressions → Click → Subscriber → Chat member → Active → Verified/Invested
```

| Этап | Конверсия (оценка) |
|------|-------------------|
| Impression → Click | 0.5–2% (CTR зависит от креатива и релевантности) |
| Click → Telegram subscriber | 50–80% (если CTA на вступление) |
| Subscriber → Chat member | 30–50% |
| Chat member → Active | 20–40% |
| Active → Verified (МТЛА) | 2–5% |
| Active → Shareholder (МТЛФ) | 1–3% |

**Стоимость конечного конверсии (CAC):**

| Конверсия | Нижняя | Верхняя | Канал |
|-----------|--------|---------|-------|
| Подписчик TG | $0.50 | $3 | TG Ads |
| Верифицированный МТЛА | $15 | $75 | TG Ads + Google |
| Пайщик МТЛФ | $50 | $200 | TG Ads + Google |

## 4. Расчёт бюджета (цель: удвоение)

### Целевые показатели роста (из §1, §5)

| Метрика | Сейчас | Цель (×2) | Рост |
|---------|--------|-----------|------|
| Верифицированные МТЛА | 100 | 200 | +100 |
| Полноправные пайщики МТЛФ | 384 | 768 | +384 |
| Подписчики TG-канала | 4556 | 6000 | +1444 |
| Участники чата | 1369 | 2000 | +631 |

### Сценарий 1: Telegram Ads + посты (предпочтительный)

- CPL: $3–10
- Стоимость привлечения 100 вериф. + 384 пайщиков (прямой путь): $3–10 × 484 = **$1450–4840**
- Дополнительно на воронку (все этапы): ×3–5 = **$4350–24000**
- **Итого (SAA): $5000–15000**

### Сценарий 2: Telegram + Google Ads

- Telegram CPL: $3–10
- Google CPL: $20–80
- Соотношение: 60% TG, 40% Google
- **Итого (SAA): $7000–20000**

### Сценарий 3: Минимальный (органический + посты)

- Только посты в каналах: ~15 постов × $200 = $3000
- Минимум CPL: $2–5
- **Итого (SAA): $2500–8000**

### Сводка сценариев

| Сценарий | Нижняя | Верхняя | SAA |
|----------|--------|---------|-----|
| TG Ads + посты | $5000 | $15000 | $8000 |

## 7. Допущения и оговорки

1. **Цифры — грубые оценки.** Точность ±50%. Реальные затраты определятся после первых тестовых запусков.
2. **Курс:** расчёт в USD. Пересчёт в eurmtl — по текущему курсу (уточнить).
3. **Аудитория:** расчёт для широкой ниши (civic/governance/activism), не крипто-спекулятивной. Крипто-ниша дороже в 3–5 раз.
4. **Делегирование:** оценка при условии, что исполнители (labr) доступны. Если нет — сроки и бюджет вырастут.
5. **ИИ-агенты:** покрывают рутину, но не заменяют людей для коммуникации и принятия решений.
