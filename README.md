# Программа медиамаркетинга Монтелиберо

Рабочий репозиторий программы медиамаркетинга экосистемы Montelibero.

## Контекст

Montelibero — самоорганизующееся сообщество с сложным продуктом: экосистема включает МТЛА (ассоциация), МТЛФ (фонд), МТЛ-суд, ТФМ и другие структуры. Высокий порог входа → нужна система вовлечения.

Цель 2026: удвоить численность ключевых структур (МТЛА, МТЛФ) по верифицированным участникам и пайщикам.
